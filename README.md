# InsightPilot

## AI-Powered Business Analysis & Decision Support

InsightPilot is an AI-powered business analysis system that transforms business data into understandable insights, investigates possible causes, validates available evidence, and provides actionable recommendations.

## Features

- Natural-language business questions
- Business performance analysis
- Key trend and change identification
- Possible cause investigation
- Evidence validation
- Confidence/reliability scoring
- Actionable recommendations
- Evidence-based decision guidance
- Interactive Streamlit dashboard

## How It Works

User → Business Question + Data → Data Analysis → Cause Investigation → Evidence Validation → Decision Support → Recommendations

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Generative AI / AI Agents
